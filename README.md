SPC PRACTICE PROJECT

Cu ECP Thickness - SPC study using a synthetic post plate copper film thickness data set, modelled on a copper electroplating process. All data is fictional.
The objective is to calculate and interpret core SPC statistics by hand, then validate the results in JASP.

PROCESS SETUP
- Measurement: Cu film thickness (nm)
- Target = 600 nm, LSL = 585 nm, USL = 615 nm
- 10 lots x 5 wafers ( so, subgroup size n = 5)

TOPICS COVERED
- Descriptive statistics - mean, median, range, variance, std deviation, WIWNU (With-in-wafer-non-uniformity)
- X-bar and R control charts (limits from A2, D3, D4)
- Short-term (R-bar/d2) vs long-term sigma
- Capability - Cp, Cpk, Pp, Ppk, Cpm
- Z-scores and estimated ppm out of spec
- Control chart zones and run rules

RESULTS

By hand calculation:
- Grand mean = 600.86
- R-bar = 6.5
- Cp/Cpk = 1.79/1.69
- Pp/Ppk = 1.75/1.65

INFERENCE

- Process is in statistical control (all points are within the spec limits).
- Cp > Cpk - the mean sits slightly above target. So, centering is the main improvement opportunity.
- Cp is close to Pp - lot-to-lot variation is small.

LEARNING OUTCOME

I have learned the concepts of statistical process contorl, and performed hand calculations to derive the results for the process setup defined in this project. Also, i have used JASP to visualise the results using control charts. Both, hand calculations and SPC using JASP has given the same results. This has enhanced the conceptual clarity, and improved my SPC skills.
